# Handoff (OpenCode maestro)
The note lives at `.digismith/sessions/opencode-maestro/note.md` (the only place you may write besides drafts). It is rewritten whole each time and stays short.

**Write:** sections Done, Decisions, Next, Open problems; first line `# <one-line state>`, second line `Updated <UTC+7 time> [UTC]`. Show it to Jack after writing. Clearing the session is Jack's action (new session in the TUI), never yours.

**Resume ("resume", "Arise"):** read the note, show the Next list as a short numbered table, ask which one to take. Never start work alone.
