Summary

A transparent local HTTP proxy that repairs TokenReply's kimi-k3 XTML tool-call leak before Claude Code ever sees it, so a single ordinary claude -p dispatch just works — superseding the manual decode/execute/resume recovery mechanism for the claude-code runner. A Depot-managed, shared, persistent local server (scripts/agentic-bridge/server.ts) that offload-implementer's claude-code runner points ANTHROPIC_BASE_URL at instead of TokenReply directly: it forwards every request, buffers the full response, and — only if it detects the leaked XTML — decodes it (reusing the existing kimi-k3-xtml-parser.ts) and converts the decoded calls into a genuine Anthropic tool_use response before relaying it, everything else passing through untouched. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (6 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 7 fix round(s) before merge.

Reference documents: the design spec and the implementation plan.

Real finding worth flagging: the infrastructure is proven to work end-to-end — a live dispatch through the proxy completed in one ordinary call, no --resume needed, a real commit resulted — but the XTML leak itself did not reproduce in any real dispatch attempted during live verification, so the actual repair logic (decode → convert → relay) remains verified only via unit tests against synthetic leaked input, not a live leak-firing observation. See backlog/tokenreply-kimi-k3-tool-calling-failure.md.

Task 5

offload-implementer wiring

Routes every claude-code-runner dispatch through the Agentic Bridge instead of TokenReply directly (documentation-only change to offload-implementer's Steps 2, 4, and 5.5, plus its Quick Reference table).

Task 6

Live end-to-end verification

Proved the proxy pathway works end-to-end in one real, live dispatch — and honestly recorded that the leak itself didn't reproduce that day, so repair-logic firing remains unit-test-verified only.
