Summary

This feature moves the clear-and-hand-off step out of finishing-a-development-branch into a new digismith:handoff skill. The skill keeps one living note for each lineage at .digismith/docs/<Clan>/<Lineage>/handoff.md. You can run it at any time, and finishing-a-development-branch calls it automatically at the end of a ticket. A small script, scripts/lineage-handoff.ts, does all the mechanical work. It maps a session title to a lineage key and a note path. It also finds the main checkout, lists the notes, and adds the .git/info/exclude line. The skill uses the script through its CLI, and the SessionStart hook imports it, so writing and reading cannot diverge. The skill text does the judgment work: it composes the note and runs the end-of-ticket cleanup checks. It also holds each clear until the note is checked, and it controls resume. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (4 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 1 fix round before merge.

Reference documents: the design spec and the implementation plan.
