Summary

This work adds dg clickup move-task. The command changes the home List of a ClickUp task through ClickUp's public API v3. ClickUpClient.moveTask sends a PUT request to an absolute v3 URL. This reuses the existing axios instance, with its v2 base URL, shared Authorization header and shared rate limiter, so no second instance is necessary. The command follows the create-list pattern: a createMoveTaskCommand(clientFactory) factory, JSON on stdout, and clickup move-task: <message> on stderr with exit code 1. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:executing-plans (2 tasks, executed directly in this session, each with a self-check before moving on).

Reference documents: the design spec and the implementation plan.
