Summary

Built digismith:depot — DigiSmith's map item V — a small utility skill that provisions and refreshes a local, sparse clone of DigiSmith's shared packages/ code at a fixed, machine-wide location (~/.digismith/repo), and wired it into digismith:bootstrap/digismith:adopt so every ticket's work starts with that clone guaranteed present. One new skill (skills/depot/SKILL.md) provides two operations — ensure (idempotent clone-if-missing, invoked automatically) and refresh (explicit fetch-and-hard-reset, invoked directly) — scoped to packages/ only via git sparse-checkout combined with a blobless partial clone, so nothing outside that directory is downloaded or materialized on a consumer machine. Followed the full Superpowers process: brainstorming → spec → writing-plans → superpowers:subagent-driven-development (3 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 2 fix round(s) before merge.

Reference documents: the design spec and the implementation plan.
