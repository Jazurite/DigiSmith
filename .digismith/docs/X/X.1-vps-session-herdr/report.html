Summary

X.1 replaces V.3's tmux/claude-based VPS session CLI with a herdr-supervised OpenCode+TokenReply one, keeping the same dg vps status/dg vps connect commands and config file while rewriting the internals. The five files under packages/cli/src/vps/ (config.ts, checks.ts, status.ts, connect.ts, shared.ts) were rewritten against herdr instead of tmux; a piece of repo-path-resolution logic previously private to depot/bridge/ was extracted to a shared module first, since connect.ts's credential/config auto-fix needs it too.

Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (6 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → live verification against the real VPS.

Reference documents: the design spec and the implementation plan.
