Summary

Fixed packages/jira-client/src/cli.ts's entry-point guard, which never matched on Windows and silently no-opped every subcommand, and added a regression test that actually exercises it. The fix is a one-line guard swap plus a new subprocess-invocation test in cli.test.ts that spawns the real CLI as a child process (node) and asserts real stdout/stderr/exit-code behavior — the only way to prove main() actually runs, since the existing tests only exercised pure helper functions and never invoked the CLI as a process at all. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:executing-plans (1 task, executed directly in this session, with a self-check before moving on).
