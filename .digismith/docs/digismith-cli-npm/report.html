Summary

Publishes @digismith/cli, an npm package whose digismith/dg binaries run V.3's vps status|connect commands from any machine, with the vps-session code relocated in as the first command group. Built as a zero-runtime-dependency workspace package with a thin src/index.ts dispatcher, and src/vps/ moved verbatim from scripts/vps-session/. The original design shipped raw .ts sources with no build step, on the assumption that Node natively strips types — that premise did not survive a real install: Node unconditionally refuses to type-strip any .ts file resolving under a node_modules directory (ERR_UNSUPPORTED_NODE_MODULES_TYPE_STRIPPING, confirmed live and independently reproduced), and every package manager installs a package there by definition. The design and plan were amended mid-implementation to a tsc build to dist/, with the bin pointing at compiled JS; the checkout-path invocation, source layout, and dispatcher logic were unaffected. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (3 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 1 fix round before merge.

Reference documents: the design spec and the implementation plan.
