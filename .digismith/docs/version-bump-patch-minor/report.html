Summary

Makes bump-plugin-version.ts distinguish a patch-worthy version bump (every commit since the base is a conventional fix(...)) from a minor-worthy one, instead of always bumping minor. A new bumpTypeSince function inspects the commit range's subjects via git log; computeNextVersion gains a bumpType parameter (defaulting to today's exact minor-bump behavior); main() wires the two together only when --base is supplied.
