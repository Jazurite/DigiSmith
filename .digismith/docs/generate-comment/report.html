Summary

Decoupled comment/message templating into a shared skill (generate-comment, map item Q.1) with three Markdown templates, then refactored the two already-shipped consumers — jira-progress-write-back (I.1) and teams-pr-review-notification (I.4) — to both call it instead of each rendering its own inline template (Q.2). generate-comment owns template selection, content-gathering questions, and filling a Markdown template, returning {markdown, headingPrefix}; a new scripts/fill-template.ts does the mechanical load-and-substitute work, and a new packages/jira-client/src/markdown-to-adf.ts converts the Jira-bound templates' filled Markdown to ADF right before I.1 posts — Teams needs no conversion at all. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (5 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 4 fix round(s) before merge.

Reference documents: the design spec and the implementation plan.
