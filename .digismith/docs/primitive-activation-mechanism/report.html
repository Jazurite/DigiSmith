Summary

Build the reusable mechanism a future vendored-skill activation will use: a fork-provenance tag convention, and an on-demand script that 3-way-diffs every vendored skill (baseline clone vs. currently-installed upstream vs. local working tree) so upstream drift and local divergence are never conflated. A single flat TypeScript file, scripts/check_vendored_skills.ts, exports small pure/testable functions plus a main() CLI entry point, run directly via Node's built-in type-stripping (no build step, no new runtime dependency); vendored/PROVENANCE.md got three doc edits recording the baseline commit and describing the new script. Followed the full Superpowers process: brainstorming → spec → writing-plans → superpowers:subagent-driven-development (6 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 3 fix round(s) before merge.

Reference documents: the design spec and the implementation plan.

What Was Delivered

Task 1

Directory resolution

Resolves which Superpowers plugin version is currently installed by picking the most-recently-modified plugin-cache directory (DirEntry, pickMostRecentDir, resolveUpstreamSkillsDir).

Task 2

Git content readers

Reads file content from a specific git commit and from the local filesystem, and lists which files existed in a skill folder at a given commit (readGitBlob, readFileIfExists, listBaselineFiles).

Task 3

Diff computation

Computes a unified diff between two strings via temp files and git diff --no-index (diffContent).

Task 4

Comparison & formatting

Categorizes a file's drift status and keeps upstream drift strictly separate from local divergence, then formats the result into a human-readable report (FileDriftStatus, FileComparison, compareFile, SkillReport, formatSkillReport).

Task 5

Main CLI orchestration

Wires everything into a runnable CLI and was verified live against the actually-installed Superpowers plugin (BASELINE_SHA, VENDORED_SKILLS, checkSkill, main).

Task 6

PROVENANCE.md documentation

Records the baseline commit, rewrites the Sync policy section, fixes a stale cross-reference, and adds the fork-provenance tag convention to the Activation checklist — the terminal task for W.2.

Build Process

Executed via superpowers:subagent-driven-development: fresh implementer subagent per task, independent spec-compliance + quality review after each.
