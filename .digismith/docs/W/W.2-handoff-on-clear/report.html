Summary

This closes a gap in finishing-a-development-branch's Step 7. Before this change, Step 7 only spoke a warning about unresolved work, with no written record. Step 7 now writes a 5-section markdown handoff to .digismith/sessions/<session-id>.md on every clear. W.10's SessionStart hook (session-init.ts) points to that file when one exists. The build has two independent halves. They share only a file-format contract: the first line is an # heading, and the file lives at .digismith/sessions/<id>.md. Task 1 builds the read side: it adds pure functions to session-init.ts that find the newest pending handoff and print a pointer. Task 2 builds the write side: it rewrites Step 7 to compose and write the handoff file. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (2 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 1 fix round before merge.
