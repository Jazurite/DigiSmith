Summary

This moves every vendored skill's leftover .superpowers/ scratch path onto .digismith/. It fixes the pre-existing SDD-workspace basename-collision bug at the same time. scripts/sdd-workspace now computes the SDD workspace location: it nests .sdd-workspace/ inside the plan's own docs folder, the same folder as design.html, plan.md, and report.html, falling back to a .sdd-workspace-<basename> sibling only when the plan file shares its folder with other plans. task-brief, review-package, and three SKILL.md files now read this location through that one script instead of repeating the rule. Separately, start-server.sh gains an optional --slug flag: it nests the brainstorming visual companion's mockup storage under .digismith/brainstorm/<slug>/ when a feature slug is known, falling back to the flat per-session bucket (renamed to .digismith/) otherwise. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (5 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 1 fix round before merge.

Reference documents: the design spec and the implementation plan.
