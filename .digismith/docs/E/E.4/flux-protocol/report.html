Skill text and script differ until DGS-159

This is deliberate. scripts/lineage-handoff.ts, its tests, the SessionStart line and .git/info/exclude still know only the old .digismith/docs/... paths. So --action path, --action ensure-excluded and --action list serve the fallback only; the SessionStart line lists only fallback notes, so a note at the new path is found by "resume" or "Arise"; and the skill checks the new path with git check-ignore and tells the human when it is not yet excluded. DGS-159 migrates the notes and adds the pattern. The skill text says the same.

The convention did not decide one case: a session title used as a folder name. The rule written into the skill: the title is the session name only when it is one safe path segment (not empty or blank, no slash, not . or .., not a lineage-key title like "A.1: Primitives"); any other title uses the old lookup; no title means ask. A worker started with a brief writes no note.
