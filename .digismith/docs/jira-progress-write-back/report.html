Summary

Built jira-progress-write-back — DigiSmith's map item I.1 — a skill that posts and updates real JIRA ADF formatting (status lozenges, emoji, a dated progress comment) on the active ticket for a single repo/PR at a time, consuming map item M's captured ephemeral URLs. It's a single new skill, triggered right after digismith:capture-ephemeral-url succeeds or on explicit request: it resolves the ticket key from the branch name, detects whichever JIRA-capable tool is available in the session, fetches the ticket's description and comments as real ADF (never the lossy markdown-rendered pseudo-HTML), drafts a Materials & Links bullet entry and, only if a Track checklist already exists, the Technical Development line's status/checkmark, composes them into a complete replacement description document, drafts a dated Progress Update comment, shows both drafts for explicit confirmation, then writes them via contentFormat: "adf". Followed the full Superpowers process: brainstorming → spec → writing-plans → superpowers:subagent-driven-development (2 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 3 fix round(s) before merge.
