Summary

Built scripts/vps-session/cli.ts, a standalone status/connect CLI that reconnects to an already-provisioned Hetzner VPS's persistent claude tmux session over SSH, and documented it as Depot's fourth managed resource. A small set of pure, unit-tested modules (config loading, SSH command construction, output parsing, status aggregation/formatting) is wired together by two thin orchestration functions (runStatusChecks, runConnect) that do the actual spawnSync-based SSH/tmux work; the orchestration functions and the final interactive attach are live-verified against the real VPS rather than unit tested, since mocking SSH would only test the mock. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (6 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 3 fix rounds before merge.

Reference documents: the design spec and the implementation plan.

What Was Delivered

Task 1

VPS config loader

VpsConfig, DEFAULT_VPS_CONFIG_PATH, and loadVpsConfig() — returns null when ~/.digismith-depot/vps.json is absent and throws a vps-session:-prefixed error when it is malformed or missing a required field.

Task 2

SSH command builders and output parsers

SshCommand argv builders for every health check (reachability, linger, toolchain, tmux list, credentials, pane command) plus the pure parsers isLingerEnabled, parseToolchainOutput, isTmuxSessionAlive, and isClaudeProcessRunning.

Task 3

Status aggregation, formatting, and orchestration

runSshCommand (one spawnSync wrapper), the StatusReport/CheckOutcome types, formatStatusReport, isFullyHealthy, and runStatusChecks, which runs the real checks and reports "tmux alive but claude exited" as its own distinct state.

Task 4

Connect auto-fix builders and orchestration

START_CLAUDE_SCRIPT, TOOLCHAIN_INSTALL_HINT, the enable-linger / write-start-script / start-tmux / attach builders, and runConnect, which checks, auto-fixes what is safe, warns on missing credentials, and attaches interactively.

Task 5

CLI entry point

node --experimental-strip-types scripts/vps-session/cli.ts <status|connect> — argv dispatch over the modules above, stopping with a plain message when no vps.json is configured.

Task 6

Depot documentation

A new "Resource: VPS Session" section in skills/depot/SKILL.md, plus its frontmatter description clause, Quick Reference rows, and Error Handling rows.
