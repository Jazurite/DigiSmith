Summary

Generates a ready-to-paste Microsoft Teams review-request message — matching Jack's own real message style exactly — either automatically offered right after a PR is created, or on direct request, covering both a single PR and a multi-repo epic (several PRs across market repos sharing one ticket). A new skill, skills/teams-pr-review-notification/SKILL.md, does all the templating and asking; it's wired into exactly one existing file, where finishing-a-development-branch's Option 2 gains a one-line offer to invoke it right after reporting a new PR's URL. No new packages, no live Teams connection of any kind — pure text templating plus AskUserQuestion prompts, reusing the existing digismith:preferences skill for a saved-default reviewer list. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (2 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 1 fix round before merge.

Reference documents: the design spec and the implementation plan.
