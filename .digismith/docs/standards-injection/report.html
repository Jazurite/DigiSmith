Final Review & Fix

The whole-branch review (dispatched on the most capable available model) came back "Ready to merge: With fixes" — one Critical finding, three Important:

SeverityFindingResolution
Critical Every skill used bare relative paths to standards/ — resolves against whatever repo the agent happens to be sitting in, not DigiSmith's own directory. Breaks in G's actual intended use (dispatched into e.g. an Emma repo). Compounded by installed plugins living in a version-scoped cache, confirmed empirically against another plugin already on this machine. Added a "Locating the Standards Library" section to all four skills: check whether cwd is DigiSmith itself, otherwise ask the user for the repo path and remember it for the session. Never read/write under the plugin cache.
Important inject-standards Step 1 unconditionally blocked on a missing index, contradicting Scenario 4's own "don't block dispatch" fallback. Step 1 now excepts Scenario 4 explicitly.
Important Cross-skill invocations used unqualified names (index-standards instead of digismith:index-standards). Qualified in all Process-step invocations.
Important index-standards had no path to refresh a description when a file's content changed without being added or deleted (the append case). Added a content-changed bucket to the diff logic and its own report line.

The Critical finding was a real architecture gap neither the original spec nor the plan resolved — it needed a decision, not a guess, so it went back to Jack before any fix was dispatched. One fix subagent addressed all four findings in a single commit; a scoped re-review confirmed everything was addressed with no new breakage.
