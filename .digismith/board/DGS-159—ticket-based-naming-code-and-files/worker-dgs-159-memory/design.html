1. Why

DGS-158 drops clan-letter and lineage naming; the ticket is the unit of work from here on. MEMORY.md at the repo root still has the old clan-letter map (26 rows, A–Y), a 6-tier build order keyed to those same letters, and an Open Questions list written in the same vocabulary. None of that can keep being live content once new tickets stop getting letters. Jack's rule for this restructure: what is already recorded in MEMORY.md is immutable — this design moves it, never edits or deletes it, and adds new sections around it for whatever a session needs to read today.

2. What "immutable" covers

Confirmed over two checkpoints with the maestro and Jack:

  • The Map (26 rows), Build Order (6 tiers, including its explanatory paragraphs), and Open Questions (3 items) move verbatim under one new labelled, frozen section at the end of the file. Not reworded, not folded, not re-ordered internally.
  • The file's opening paragraph is not edited either, even though one clause in it ("the map of what gets built, and the order it gets built in") becomes misleading. A new, separately-dated status block is inserted directly after it instead — it corrects the orientation without touching the recorded sentence.
  • Everything else recorded in Philosophy, Structure, What Superpowers Already Covers, Relationship to 2. Career/, and Conventions is unmodified prose, including the bits of it that reference map letters inline (e.g. "Relationship to 2. Career/" names map item C and Tier 6; two Conventions bullets name map items O and P). Those stay exactly as written — the terms they reference remain findable in the frozen section further down the same file.

5. New: "Where work is tracked now" (verbatim text)

## Where work is tracked now

Tickets, not clan letters, are the unit of work (DGS-158, adopted 2026-10-04). ClickUp is the
source of truth for what's active and what's planned — this file no longer tracks either. A
ticket's working files live in `.digismith/board/<KEY>—<slug>/`; session files live in
`.digismith/sessions/`. No new letter or lineage number gets assigned to anything, ever again.
Shipped work is recorded automatically in `.digismith/history.html` by the history hook, not by
hand here. The clan-letter map near the end of this file is a frozen snapshot of everything built
before this cutover — read it for historical context, never extend it.
