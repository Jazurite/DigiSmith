DGS-267 create-folder --parent-folder — Implementation Report

Ticket: DGS-267Date: 2026-10-13

Summary

dg clickup create-folder can now put a new folder inside a parent folder (for example Clans) with --parent-folder. The public API cannot create a folder with a parent, so the command creates at the top level and then moves the folder with the same client method as move-folder. Built on branch dgs-267-create-folder-parent; not merged.

Built

  • create-folder --name <n> [--parent-folder <id>] [--yes]. Without --parent-folder nothing changes.
  • With it: a dry run unless --yes. The dry run builds no client and prints POST /space/<id>/folder and PUT /folder/<new folder id>/position.
  • With --yes: create, move, read back parent_folder.
  • --yes alone and a non-digit parent are refused before any call.

Half-done state

If the create works and the move fails, the command exits 1 and prints the new folder id, its name and the line dg clickup move-folder --folder <id> --parent <p> --yes. It never deletes and never retries. If only the read-back fails, it exits 0 with a note.
