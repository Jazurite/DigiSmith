Inject the conversation-voice rules at session start

Date: 2026-10-27Ticket: DGS-679

Contents

  1. What and why
  2. Design
  3. Files and tests
  4. Out of scope

What and why

The SessionStart hook (scripts/session-init.ts) prints a banner such as voices=technical+conversation. It never prints the rules. A session that does not run digismith:voice or inject-standards never reads standards/global/ai-voice-conversational.md. On 2026-10-27 this produced long, recap-heavy replies in the DGS-671 session, with both voices on.

Front-end analogy: the banner is a feature flag that says "on", and nothing loads the code behind the flag. This ticket loads a small part of it.

Design

  • One extra line after the banner, only when the conversation voice is on: the 11 rule titles and the path to the standard. About 150 tokens. No examples, no full text.
  • Titles come from the standard file (the ### N. title headings under ## Rules), so the line cannot drift from the standard. No copied text in code.
  • Where it lives: scripts/voice-init.ts gains two exports: readRuleTitles(standardPath) and conversationDigest(standardPath, dir). The voice state check stays in voice-init.ts, next to the existing summary. session-init.ts gains loadVoiceDigest(voiceInitPath, standardPath) and prints the result in main.
  • Silent on any problem: no profile (the whole hook is silent without a .digismith profile), voice off, file missing, no titles found, or an older voice-init.ts without the new export: no line, no error. A failure inside the digest never changes the exit code (the session must always start).
  • Technical voice and the banner format are unchanged. The standard path is resolved from the script folder: scripts/../standards/global/ai-voice-conversational.md, which holds in the plugin cache too.

Files and tests

FileChange
scripts/voice-init.tsAdd readRuleTitles, conversationDigest.
scripts/voice-init.test.tsTitles parsed from a fixture; the real standard gives 11 titles; digest present when on, null when conversation is off, null when the file is missing.
scripts/session-init.tsAdd loadVoiceDigest; print it in main after the banner; never set the exit code.
scripts/session-init.test.tsloadVoiceDigest: null without a voice-init file, null when the module has no digest export, returns the module's string and passes the standard path through.

Out of scope

  • The full rule text or examples, the technical voice, the banner format.
  • Any change to digismith:voice or inject-standards.
  • A digest of other standards.
