Autonomous jobs run the built CLI

Date: 2026-10-22 Ticket: DGS-587

Contents

  1. Problem
  2. Design
  3. Missing dist
  4. Tests

Problem

The Nexus jobs autonomous-scan and autonomous-report run the CLI source of the depot clone with --experimental-strip-types. The depot clone has no node_modules, so yargs is missing. The source also uses parameter properties (tracker-clickup.ts:37), which type stripping refuses. Vitest transforms the code, so the tests never showed it.

Design

  • registry.ts: DG becomes [join(MAIN_CHECKOUT, 'packages', 'cli', 'dist', 'index.js')]. No strip-types flag. MAIN_CHECKOUT moves above DG. This is the same build the global dg runs.
  • Replace parameter properties with plain fields in tracker-clickup.ts and in steward/fake-tracker.test-util.ts. A scan found no enum or namespace under packages/cli/src/.
  • Add a smoke test that spawns node --experimental-strip-types packages/cli/src/index.ts --help and ... autonomous --help. It fails when a source file cannot be type-stripped.
  • After the merge the conductor runs scripts/nexus-api/install.sh. The Builder does not.

Missing dist

dist is rebuilt by the finish hooks and by pnpm --filter @digismith/cli build. If dist is missing, the job fails at once. The registry command is node <MAIN_CHECKOUT>/packages/cli/dist/index.js autonomous ..., so node prints Error: Cannot find module '<MAIN_CHECKOUT>/packages/cli/dist/index.js' and exits 1. The job log shows this. No wrapper is added.

Tests

  • Registry test: the scan and report commands use process.execPath, the first arg is the main checkout dist/index.js, and no arg is --experimental-strip-types.
  • Smoke test (packages/cli/src/strip-types.smoke.test.ts): two child processes, each exits 0 and prints help.
