Summary

Adds the dg reviewer command group: pack builds the input folder of one review and picks its model, and table joins review findings with verdict lines into findings.md. The code is pure functions in packages/cli/src/reviewer/: file in, file out, no network. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (6 tasks of the plan, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 1 fix round before merge. This ticket covers Tasks 1 to 6 of the DGS-529 plan.

Reference documents: the design spec and the implementation plan.
