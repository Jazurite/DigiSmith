Summary

Each SDD task posts one plain-text comment with its tokens, list-price cost, agent time and review numbers on its ClickUp ticket, and the finishing skill writes the ticket total into the description once. A shared module collects the ticket's responses, assigns each to a task, prices each response alone and renders the text. Two dg clickup commands (task-stamp, ticket-total) use it, and the two skills call them. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (9 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 10 fix round(s) before merge.

Reference documents: the implementation plan. The review record is in findings.md.
