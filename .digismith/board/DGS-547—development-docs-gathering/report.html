Summary

Attach the spec, plan, reviews, ledger summary, report and tokens.json to the ClickUp ticket automatically, once each at its final moment, through one new dg command. One command dg clickup attach-record (file mode plus two render kinds) uses a pure decision function that compares the file's sha-256 with a depot state file and the task's current attachments, so a re-run adds nothing; skills get one hook line each, which never blocks. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (7 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 3 fix rounds before merge.

Reference documents: the spec and the implementation plan.

What Was Delivered

Task 1

The attachment state store

A depot state file per ticket records what was attached (name, sha-256, id); the latest record per name wins, writes are atomic, and bad elements are dropped on read.

Task 2

The decision function

A pure decision function says skip or upload, names the superseded id, and warns about an unknown or lost-record same-titled attachment.

Task 3

The ledger summary renderer

A pure renderer turns the SDD ledger into one markdown table plus the whole-branch review lines.

Task 4

The dg clickup attach-record command (file mode)

One new command attaches a file once per content, never deletes, names the attachment by its file name, and exits 1 when the depot record write fails.

Task 5

The render kinds (--kind reviews|ledger-summary)

The command can render the reviews table or the ledger summary into a temp folder and attach it under its own name.

Task 6

Skill hook lines

Six skills send each build-record file to the ClickUp ticket once, with a hook line that never blocks.

Task 7

The wiring guard test

A test pins the hook lines, their order and the failure wording in the skills.

Build Process

Executed via digismith:subagent-driven-development: fresh implementer subagent per task, independent spec-compliance + quality review after each.
