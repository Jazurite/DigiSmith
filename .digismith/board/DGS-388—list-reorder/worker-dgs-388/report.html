Summary

dg clickup move-list now reorders a list inside its own folder. It sends the position only, as the web app does, because ClickUp answers 400 when the folder is sent for the folder the list is already in.

Built

  • ClickUpClient.getList reads the list's current folder. move-list reads it first, a dry run too.
  • The folder is the current one, or left out: position-only body, --position required. Another folder: the old folder change.
  • A folderless list without --folder and a failed read both refuse. Dry run and --yes say which body is sent.
  • FrontdoorClient shows ClickUp's error body in the message of a failed call.
  • Tests added for the client and the command. The whole repo passes with FORCE_COLOR=1; the CLI build is clean.
