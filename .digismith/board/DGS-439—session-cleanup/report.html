DGS-439: dg sessions cleanup

Summary

dg sessions cleanup [--project <p>] [--yes] deletes archived closed or lost session cards whose ended is strictly older than CLEANUP_DAYS (3, one constant). It is a dry run by default. A real run appends one line per deleted file to sessions/cleanup.log. 16 new tests pass and the whole suite passes.

Allow-list

Only sessions/<project>/archive/*.yml: regular files, status closed or lost, ended strictly older than 3 days. Symlinks, open cards, a missing or unreadable ended and other folders are kept. A card that does not parse is kept, reported, and the exit code is 1. Notes, orders, identities, conductor state and the log are never touched.

Known gaps

  • No worker-scratch folder exists, so there is no scratch rule. A named path is a later ticket.
  • The conductor log part waits: no separate log exists.
  • DGS-443 had no plan.md yet, so its note-path test is not added. Re-check before merge.
  • The nightly trigger is DGS-434, not this ticket.
