Summary

A read-only Nightwatch dashboard (Operations, Attention, Runs, Run detail, Plan) in the Nexus web app, fed by new /api/v1/nightwatch/ routes that run the built CLI. A new dg nightwatch view <name> --json command calls the existing Nightwatch readers and prints one JSON document; the Nexus API spawns the built CLI, caches the answer for 5 s and checks it with zod schemas; the Nuxt app has static pages under /nightwatch/ that poll every 10 s. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (12 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 11 fix rounds before merge, and 2 more rounds for the final review.

Reference documents: the design spec and the implementation plan.

How Jack opens each screen

On the tailnet, open https://pazurite.com/nightwatch/ and then the page paths below. No login in v1. On the Workbox itself the site answers at https://127.0.0.1:8443 with the Host header pazurite.com (for example curl -k -H 'Host: pazurite.com' https://127.0.0.1:8443/nightwatch/); the API is at http://127.0.0.1:4300/api/v1/nightwatch/overview.

  • Operations: /nightwatch/
  • Attention: /nightwatch/attention
  • Runs: /nightwatch/runs
  • Run detail: /nightwatch/run?id=<run-id>
  • Plan: /nightwatch/plan?ticket=<KEY>
