Date: 2026-10-13. Branch dgs-466. Not merged; installed in the depot only.

Summary

GET /api/<version>/power-metrics now starts with verdict: status (ok, busy, hot, throttling, unknown; the worst wins), a one-sentence summary and reasons. A pure function computes it from fields the API already reads.

  • Hot: CPU or GPU at 90 C or more, fan at 4503 rpm or more (85 % of the measured 5297 rpm maximum).
  • Hot, too: CPU at 85 C or more while the fan is within 10 % of its real minimum (1836 rpm, so at most 2019.6 rpm): "The CPU is at 94 C but the fan is still at its slowest speed."
  • Busy: memory under 15 % free, or CPU under 20 % idle.
  • Throttling: thermal pressure above Nominal, a power limit, prochots, or a thermal/power cause in performanceLimitedDueTo (MAX_TURBO_LIMIT is normal and counts as ok).
  • Unknown: the powermetrics read failed or timed out; the live fields still count.
  • Load average and cpuThermalLevel are not judged.

Tests: 106 pass. Review: no findings. On a scratch port the depot copy reported this Mac as throttling (thermal pressure Moderate, CPU 94 C).
