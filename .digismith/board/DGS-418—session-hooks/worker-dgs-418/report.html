DGS-418 session hooks, write, close and sweep cards — Implementation Report

Ticket: DGS-418Date: 2026-10-13

Summary

Plugin hooks write a session card at SessionStart, refresh it on each prompt (throttled to 60 s) and close and archive it at SessionEnd with a handoff in the state note. A read-only sweep script marks a dead card lost. Built on branch dgs-418, merge-ready, not merged.

Built

  • Hooks in hooks/hooks.json: card writer first at SessionStart; one UserPromptSubmit command with a pre-prompt handler list then the heartbeat; SessionEnd. No .claude/settings.json change.
  • Fail safe: the card comes only from an env allow-list; no valid role and project, a line break in a value or an invalid card writes no card. Every hook exits 0.
  • Close: ended and result on the card, archived; handoff block appended at the end of the state note.
  • Sweep: lost only when the heartbeat is stale and the herdr session is gone; anything unverifiable is never marked; dry run by default; never deletes.
  • 35 new tests with a temp depot and fake events; on DGS-417's real card API after the rebase; full suite 121 files, 1732 tests, CLI build clean.

Review

Claude whole-branch review. Fixed with tests: symlinked entry guard, NaN stale threshold and unparseable last_seen, empty or partial herdr list, line-break injection from env. Documented, not fixed: nested claude -p inherits the env; touch/close race (DGS-417 module); state path not checked; machine ignored by the sweep.

  • Starters set DIGISMITH_* (boot script, Maestro identity); until then real sessions write no card.
