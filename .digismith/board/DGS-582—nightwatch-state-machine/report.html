Summary

Plain code in Nexus holds the state of one unattended ticket (claimed, building, review, merge-ready, merged, released), moves it only on proof from files, commits and refs, orders the conductor in bounded steps, and keeps an append-only action journal that a restart reconciles without repeating a merge. One pure function advanceTicket sits among small units in packages/cli/src/autonomous/: journal, phase state in lock.json, read-only observers, input-box classifier, reconcile, act and tick. Every outside effect is injected, so tests use fakes. The DGS-486 scan calls the tick whenever a lock exists. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (13 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 6 fix rounds before merge. The findings table is in findings.md; the conductor text for the Maestro is runbook-text.md.

Reference documents: the design spec and the implementation plan.
