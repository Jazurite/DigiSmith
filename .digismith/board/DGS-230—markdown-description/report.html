dg clickup --markdown-description — Implementation Report

Ticket: DGS-230 Date: 2026-10-11

dg clickup create-task and update-task now take --markdown-description <text> and --markdown-description-file <path> (public API field markdown_description), so ClickUp renders Markdown instead of showing it raw. The DGS-327 bulk move of about 150 backlog files into ticket descriptions needs this.

What it ships

  • The three description flags (--description, --markdown-description, --markdown-description-file) are mutually exclusive.
  • get-task --markdown sends include_markdown_description=true.
  • Guards: a BOM is stripped; empty text, or an empty or BOM-only file, is refused; a repeated flag is refused. The request body is built before the client, so a flag conflict or a missing file needs no credentials.
  • README updated.
