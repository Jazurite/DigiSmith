DGS-197: dg clickup --parent — Implementation Report

Date: 2026-10-09 Ticket: DGS-197

create-task and update-task take --parent <task id>. An empty value clears the parent.

Findings from the live API

  • A subtask cannot be created in a different list than its parent (400, ITEM_137).
  • update-task --parent works across lists and moves the task into the parent's list.
  • ClickUp ignores null, "" and false for parent. Only "none" clears it, so an empty --parent sends "none".

Checks

Acceptance on a throwaway task: set, read back, clear, create with parent. All passed. Throwaways archived, none deleted. Tests: 942 passed; only index.e2e fails, as on main.

Not tested

Whether moving a task into the parent's list remaps its status.
