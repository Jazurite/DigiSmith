Running counters tick every second — Implementation Report

Date: 2026-10-26 Ticket: DGS-627 Commit range: 25aae445..1d1794c8

The Oculus counters on a running row (Duration, phase time, Elapsed, the run page's current step and budget bar) now count every second, only while the tab is visible and a shown run is running; otherwise the page clock stays at 30 s, and only the time text re-renders.

What shipped

useNow takes a fast option and runs one timer at 1 s or 30 s, restarting in the same tick when the rate changes or the tab returns. A new renderless OcTick component reads the page clock inside its slot, so a tick re-renders the time text and not the table around it. Ended rows never read the clock. The counter is not a live region. The run page's budget minutes follow the clock from phaseSince.
