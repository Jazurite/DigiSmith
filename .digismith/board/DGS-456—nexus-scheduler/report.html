Summary

The scheduler runs DigiSmith's timed jobs inside the Nexus API process, with a jobs API (list, run log, run now) and a failure comment on DGS-436. A window may cross midnight (23:00 to 06:00 UTC+7), and a job may repeat inside its window with one run per slot and at most one catch-up run after downtime. No real job is registered; selftest is the only entry, and the Lights-Out scan job (DGS-486) is added later as one registry entry. Run now works from a process on the Workbox that reads the token file. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (10 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 1 fix round before merge.

Reference documents: the design spec and the implementation plan.
