Summary

Every worker run gets a frozen run.json at dispatch and an append-only events.jsonl written by plugin hooks and by dg run event, with dg run list, show and tail to read them. A small library under packages/cli/src/run/ (node:fs and node:path only in the hook path) holds the paths, the run record, the locked event writer, the hook handler and the readers; scripts/run-events/hook-cli.ts is a thin script for the hooks; hooks/hooks.json gets five new commands that test DIGISMITH_RUN_ID in the shell before node starts. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (8 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 8 fix rounds before merge.

Reference documents: the design spec and the implementation plan. The rules for the conductor, the file-order rule and the hook speed note are in report.md.
