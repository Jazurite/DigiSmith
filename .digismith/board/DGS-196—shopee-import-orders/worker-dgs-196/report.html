DGS-196: dg shopee import-orders — Implementation Report

Date: 2026-10-08 Ticket: DGS-196 ClickUp 14zcebrv55w, list C.2: CLI Scope: packages/cli/src/shopee/

1. Summary

dg shopee import-orders lists Jack's own Shopee VN purchases from a Proxyman Raw export folder, a saved paste, or stdin. It makes no call to Shopee. The purchase date comes from the order detail's create_time, so an order with no captured detail shows MISSING and is counted. On Jack's real export (7 list pages) the command gave 34 orders, and 26 with a purchase date after the skips and --only-dated.

2. What changed

  • Input: a folder (a Request file is read for line 1 only, a Response file for its body only), pasted Proxyman text (only the URL line and the response JSON), or - for stdin.
  • Output: table, --json or --csv, one row per line item. Money is divided by 100000, currency defaults to VND, times are UTC+7 first with UTC in brackets.
  • List and detail: orders are the union of list ids and detail ids. The list also supplies lines, total and status, so an order with no detail still prints its items. A bundle is one row at the bundle price, with the part names joined by +.
  • Skips, all counted in the footer and JSON summary: cancelled orders (automatic), --skip and --skip-file (by hand), --only-dated (no purchase date), refund lines (defensive rule).
  • Paging: the footer names the captured list pages and the next offset not captured.
  • Privacy: the detail parser reads an allow-list of fields. Shipping and payment data never enter the result. Tests plant dummy secrets in fake Request sections and fake response headers, and prove none reach stdout, stderr, JSON, CSV or an error.

Where the work differs from the first design: the input moved from a capture folder to a pasted text and a Proxyman export folder (Jack's correction), the list shape is new_data.order_or_checkout_data, and the cancel, skip, bundle and paging rules were added after Jack ran the real exports. design.html and plan.md are the checkpoint 1 versions. This report and backlog/shopee-import-orders.md describe the final behavior.
