Summary

GET /api/<version>/power-metrics reads the Workbox on demand and answers JSON: CPU and GPU die temperature, fan, thermal pressure and levels, prochots, package power, CPU frequency, top tasks, raw battery/network/disk/GPU lines (root-only, from one fixed sudo -n powermetrics command), and load, CPU idle, memory free, top processes and the OpenCode server's memory (no root). One run at a time, a 5 s cache, a 10 s timeout. A failed read gives HTTP 200 with source.status and null root fields; 503 only when nothing can be read. Caddy forwards /api/* with no login (Jack, 2026-10-13: tailnet only, read-only; login design: DGS-458). The version prefix is one constant (v1, a placeholder for DGS-452).

What changed

  • scripts/nexus-api/: the API (TypeScript, Node 24, no dependencies), 10 test files, install.sh, wrapper and LaunchAgent templates, three fixtures (two real powermetrics outputs, one synthetic block).
  • scripts/caddy/: the /api/* route (reverse_proxy with header_up -Authorization), tests. The login (basic auth, NEXUS_BASIC_AUTH_HASH, a start-up fallback) was built, tested, reviewed and then removed at Jack's word; it lives on as DGS-458. caddy-run.sh reads only the Cloudflare token again.
  • Board folder: ticket, design (rev 3), plan with Jack's step list, probe-smc.c (a record of the dropped option (b)).

Decisions on the way (all by Jack, 2026-10-13)

Degraded 200 instead of 503; /api/* routed in Caddy (first gated with basic auth, then ungated: tailnet only, read-only); no collector (moved to DGS-455); option (a), a narrow sudoers rule, over an SMC helper (b) because all metrics must be readable; broad sampler set. Option (b) was measured on this Mac without root (fan, CPU and GPU temperatures, thermal levels all readable; no prochots) and is kept only as a record.
