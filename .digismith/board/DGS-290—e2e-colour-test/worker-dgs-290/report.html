DGS-290 e2e help colour test without a colour terminal — Implementation Report

Ticket: DGS-290Date: 2026-10-11

Summary

The e2e --help test expected coloured headers and failed whenever the run had no colour terminal. It now sets its own environment. The CLI is unchanged.

Built

  • Cause: picocolors turns colour on only with a TTY or FORCE_COLOR, and NO_COLOR beats both.
  • One file, packages/cli/src/index.e2e.test.ts: run() takes an optional env; the --help test spawns with FORCE_COLOR=1 and no NO_COLOR. The open-then-close colour assertion stays. The other two tests have no colour dependency.
  • Red first: without FORCE_COLOR, 1 of 601 CLI tests failed. After the change 601 of 601 pass, also with NO_COLOR=1.
  • Repo-wide pnpm test: 1348 of 1348 without FORCE_COLOR and 1348 of 1348 with it.
