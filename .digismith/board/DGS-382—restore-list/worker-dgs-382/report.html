Ticket: DGS-382Date: 2026-10-11

Summary

dg clickup restore-list restores a deleted List from the ClickUp Trash, with its tasks. It is a dry run unless --yes is given.

Built

  • FrontdoorClient.restoreList sends PUT /v1/subcategory/{id}/undo with body {"method":"delete"}, as captured. ClickUp's error body shows in the message of a failed call.
  • The command takes --list (digits only). A dry run builds no client and sends nothing. --yes sends the call and points at dg clickup get-lists for the read-back.
  • Tests added for the client and the command, mocks only. The whole repo passes with FORCE_COLOR=1; the CLI build is clean.
  • No allow rule: every real restore prompts for Jack.

Not built

Restore of a folder and of a task. A capture is needed before adding them.
