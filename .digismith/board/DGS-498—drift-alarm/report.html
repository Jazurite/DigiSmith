Drift alarm — Implementation Report

Summary

Line-ending and mode drift is now visible. scripts/workbox-health/drift-check.ts counts eol drift and mode drift per checkout and ignores the repo config (core.autocrlf=input, core.fileMode=false). A fourth SessionStart hook prints one alarm line when the current checkout drifts. workbox-health has a "git drift" section and install.sh installs a drift-check wrapper into the depot. Built from the plan in three commits. Reference documents: the spec and the plan.
