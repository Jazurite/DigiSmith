Summary

A 5-minute job in the existing Nexus API scheduler counts each run's tokens and list-price cost, then writes a burn file and a seat file. Oculus shows Tokens and Cost per run, a per-model card, burn per hour and the seat windows. The counting lives in packages/cli/src/tokens/ and reads each transcript from where it stopped. dg tokens runs writes tokens.json next to each run, runs/.tokens/burn.json and usage-probe/seats.json. The Oculus views only read these files and show "-" when a file is missing or stale. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (8 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 2 fix round(s) before merge.

Reference documents: the design spec and the implementation plan.

What Was Delivered

Task 1

The Anthropic price table moves into the CLI, with a version

packages/cli/src/tokens/prices/ holds the one Anthropic table, ANTHROPIC_PRICES_VERSION = "2026-10-18", costFromPricing and resolveAnthropicPrice (own keys only); scripts/token-counter re-exports them.

Task 2

Read a transcript from a byte offset

readUsageFrom reads only full lines after a FileCursor, restarts on a shrunk or replaced file, and skips lines over 1 MB; one shared parseUsageLine.

Task 3

Count one run (state, cost, buckets, tokens.json)

countRun writes tokens.json (five classes per model, list-price cost, 5-min buckets) and tokens.state.json (cursors and per-response counts, no text, no folder path).

Task 4

The seat file from the probe readings

writeSeats turns the conductor's out-<seat>.json probe files into usage-probe/seats.json: seat, reading time and the two windows only.

Task 5

dg tokens runs, the burn file, the scheduler job, the README

dg tokens runs updates every run in scope, writes runs/.tokens/burn.json and seats.json; the oculus-tokens job runs it every 5 min in the existing Nexus API scheduler.

Task 6

Oculus views and the shared schema

The Oculus views read the three files with the 15-min freshness rules: row tokens, run tokens, overview burn and seats; a malformed file gives null, never a view error.

Task 7

Oculus web: Tokens and Cost columns, the tokens card, the top bar

Tokens and Cost columns in the Runs table, a Tokens and cost card on the run page, burn per hour and seat windows in the top bar, with stories, baselines, e2e and axe.

Task 8

A DGS-598-shaped run

A test shows an automatic run is counted across both sessions of a /clear; no code change was needed.
