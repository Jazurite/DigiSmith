Summary

dg autonomous scan | away | back | release | report | status plus two Nexus scheduler jobs. At night or while Jack is away, an hourly scan claims one ready to do ticket, hands it to the digismith-conductor, and reports when Jack is back. The code is plain TypeScript in packages/cli/src/autonomous/, one unit per file; every outside effect (ClickUp, herdr, Nexus, clock, depot folder) is passed in, so tests use fakes. The scan never starts a worker; it writes an order and prompts the conductor. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (16 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 4 fix round(s) before merge.

Reference documents: the design spec and the implementation plan. Review findings: findings.md. Mutation checks: report.md.
