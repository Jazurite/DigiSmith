DGS-401 let the OpenCode Maestro dispatch — Implementation Report

Ticket: DGS-401Date: 2026-10-11

Summary

The OpenCode Maestro (agents maestro and maestro-review) can now write worker briefs and board files and run tab create, agent start, agent prompt and agent wait in w2 without being blocked. Installed live and proven by Jack's probes, including the first use (one tab created and closed).

Cause

The config was not the problem; the safety plugin blocked the calls after the config allowed them or Jack approved them.

  • Every write in an allowed folder went to the Haiku reviewer, which used all 400 output tokens and returned no text; the plugin failed closed.
  • The v2 adapter stubs the session messages, so the reviewer saw no user request and blocked tab create.
  • The edit check used a hard-coded folder list and ignored the config's allow globs.
  • opencode-boot rebuilds v2/ from the payload at every start, so the fix goes in the repo, then install.sh, then the restart.

Built

  • Writes are allowed by rules, no model, on the real path (no .., symlinks resolved): opencode-maestro/*, dgs-<n>/brief.md, files directly in board/<ticket>/ and its worker-*/ folders. Secret paths, outside-root paths, secret text, deletes and moves out block first.
  • The four dispatch verbs are allowed by rules. close stop run send rename focus stay on ask and go to the reviewer (1500 tokens; a bad reply or a down gateway still blocks).
  • Config: edit and bash allows placed before the deny block, so a deny still wins. The plugin throws before OpenCode can grant anything.
  • Prompt: active Maestro, new role words, today's rules.
  • Tests, written first: test-dgs-401.mjs 60, test-config-order.mjs, test-rules.mjs 50 (free, no model).

First use

Jack restarted opencode-boot. Probes passed: write dgs-999/brief.md, agent list, tab create (no prompt) and tab close (Jack approved): one tab created and closed. A write to .claude/settings.json, a read of a .env path and ls /etc stayed blocked. Backups carry the suffix .before-dgs-401-20261011; restore.md lists the restore commands.

Review

Claude whole-branch review. Fixed with tests: a dangling symlink at the last path component passed the symlink check; duplicate --workspace / --pane, -w and = forms passed the workspace check. Not fixed: no per-verb flag whitelist (herdr's flags are unverified; the wrapper pins workspace and pane). The review fixes reach the live server with the next opencode-boot.

Scope

DGS-346 stays its own ticket; only the deny shapes were run here.
