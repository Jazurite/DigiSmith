Summary

Finishing (Option 1) posts one fixed-shape ClickUp progress comment per merge through a new dg clickup merge-comment command. A pure renderer builds the comment from facts (range, commits, version, time, report pointer) plus four short agent-supplied fields. A thin command gathers the git facts, skips a head already posted (depot record), posts through a shared postComment helper extracted from add-comment, and never blocks. The finishing skill calls it after attach-record, in the hook style || true. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (5 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 1 fix wave before merge.

Reference documents: the design spec and the implementation plan.
