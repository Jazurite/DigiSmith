DGS-81 Task keys in dg clickup — Implementation Report

Ticket: DGS-81Date: 2026-10-13

Summary

get-task, update-task (including a non-empty --parent), upload-attachment and move-task now accept a custom key such as DGS-411 as well as a raw ClickUp id. A key is looked up once and the real id is used for every later call; a raw id behaves as before. The whole suite passes (1869).

What changed

  • refs.ts: resolveTaskId(client, ref). A key is looked up once with getTaskByRef; a raw id passes through with no call. A 404 on a key throws "task key DGS-999 not found (checked with custom_task_ids and the team id)"; other errors are unchanged.
  • client.ts: getTaskByRef(ref, extraParams?) only.
  • get-task: a key uses getTaskByRef (also with --markdown); a raw id keeps the old call.
  • update-task, upload-attachment, move-task: resolve --task once. In update-task the lookup runs after the body is built and the client is created, before any task call. In move-task --list is not resolved.
  • A lower-case key is detected as a key and sent unchanged; ClickUp decides.

Whole-branch review

Claude review: "ready after fixes". Fixed: update-task key test with --field and one date flag, --parent resolution, key 404 message, lower-case wording, get-task raw id with --markdown test, plan.md placement.
