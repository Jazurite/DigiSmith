DGS-81 custom task ids in dg clickup — Implementation Report

Ticket: DGS-81

What changed

  • refs.ts: resolveTaskId(client, ref). A key is looked up once with getTaskByRef; a raw id passes through with no call.
  • client.ts: getTaskByRef(ref, extraParams?) only.
  • get-task: a key uses getTaskByRef (also with --markdown); a raw id keeps the old call.
  • update-task, upload-attachment, move-task: resolve --task once. In update-task the lookup runs after the body is built, before any task call. In move-task --list is not resolved.

Also changed after review

  • --parent (update-task): a non-empty value other than none is resolved; an empty value still clears.
  • A 404 on a key: "task key DGS-999 not found (checked with custom_task_ids and the team id)"; other errors unchanged.
  • A lower-case key is detected and sent unchanged; ClickUp decides. No promise it works.
