Summary

dg clickup update-field can now set or clear the default value of a dropdown custom field, with --default and --clear-default. The call is the Frontdoor PUT that Jack's capture showed. The default goes out by option name. After a --yes write the command reads the field again and fails if the default did not stick. get-field and list-fields show the default. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (4 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 5 fix rounds before merge.
