Summary

Adopted user-manual guides in ClickUp list F.9 are now readable from the command line and listed at session start. dg guide list shows every adopted guide, dg guide <name> prints one page, dg guide refresh rewrites the cache. A Maestro session gets one index line per guide (never a page body, at most 3000 bytes). The hooks/ folder is untouched.

What changed

  • packages/cli/src/guide/: parser (adoption test, slug, "When to use it"), depot cache with an exclusive refresh lock, lookup by slug, key or prefix, refresh from F.9 (one list call with markdown_description), and the dg guide command with an 8-second limit and a cache fallback.
  • scripts/guides/index-text.ts: builds the capped index block from index.json only, and starts a background refresh when the cache is older than 15 minutes.
  • scripts/session-cards/card-hook.ts: identityContext appends the block for a Maestro identity. Workers and conductors get nothing.
  • Tests: a contract test runs the real refresh into a temp depot and reads the result with the hook side; the hooks.json test pins the hook count of every event.
