Summary

Hallmark agent time counted task_end - task_start, so a stalled build counted in full: DGS-546 task 8 showed 182 h 21 min. Agent time is now active time. For each closed window, the spans between consecutive responses of the window's own session (subagents included) are added, and a gap over ACTIVE_GAP_CAP_SECONDS (600 s) is dropped. The wall-clock window stays as a second line, so a stall stays visible. task-stamp and ticket-total use the same rule; posted comments are not rewritten, and ticket-total recomputes. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (7 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 3 fix rounds before merge (task 2, task 6, final wave).
