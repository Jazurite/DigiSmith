Summary

The Steward leaves a sane start date on a ticket at started, and merged never stops on ClickUp's ITEM_238. All changes are in packages/cli/src/steward/event.ts. At the top of apply, at every event, the Steward repairs the dates from the snapshot it already read. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (5 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 1 fix wave before merge.

Reference documents: the design spec and the implementation plan.
