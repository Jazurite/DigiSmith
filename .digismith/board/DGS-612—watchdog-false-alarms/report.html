Summary

The watchdog reads the herdr status of a pane, so a live builder that waits or runs a long subagent no longer reads lost or stalled. A really gone pane still reads lost, and a waiting permission prompt still reads blocked. The watch pass closes the items of superseded and finished runs, a retry targets only the newest builder run, Oculus uses the live pane, and the merge order passes the merge commit to the release. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (5 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 5 fix rounds before merge.

Reference documents: the implementation plan. The review record is in findings.md.
