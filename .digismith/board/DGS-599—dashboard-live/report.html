Summary

Rename the Nightwatch dashboard surface to Oculus, serve it as its own static site for oculus.pazurite.com, and make its index page show every herdr agent on the Workbox (all workspaces) with the attention summary, a disconnected state backed by a depot snapshot, and the side bar clear of the left edge. The CLI stays the only reader of depot files and of herdr: a new read-only view dg oculus view live runs herdr with one fixed argv and joins agents to run records. The Nexus API serves it at /api/v1/oculus/live through the existing 5 s cached, single-flight reader and keeps the last good answer in $DEPOT/nexus/state/. One Nuxt project builds two static sites (NEXUS_SITE=life|oculus, outputs .output/ and .output-oculus/); build-www.sh publishes both behind two symlinks. Caddy and DNS changes are repo files only here; the live change is a separate step after the merge. Followed the full Superpowers process: brainstorming → spec → writing-plans → digismith:subagent-driven-development (9 tasks, each dispatched to a fresh implementer subagent and independently reviewed) → a final whole-branch review, plus 2 fix rounds before merge.

Reference documents: the design spec and the implementation plan.
