DGS-594 + DGS-595 Jira inline images — Implementation Report

Tickets: DGS-594, DGS-595Date: 2026-10-23

Summary

markdown-to-adf now turns a whole-line ![alt](media:<mediaId>?width=&size=) token into an ADF mediaSingle image and {status:TEXT|color} into a status node. The Jira progress skills upload screenshots with upload-attachment and use those tokens. The full suite passes.

What changed

Package: packages/jira-client/src/markdown-to-adf.ts. Width must be 1-100, size needs two positive numbers, and an unknown or duplicate parameter, other image syntax, a media token inside text, an unknown status color, and a malformed status token all throw.

Skills: generate-comment collects screenshots, shows the file list, uploads them, and writes one token per line (a [filename](contentUrl) link when there is no mediaId; sips only for sizes). It asks Jack first, unless Jack's own message already orders the upload. jira-progress-write-back passes the ticket key and names leftover attachments (id and filename) on cancel and failure.
